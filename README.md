# 金额大写 rmb · 填金额直接出人民币大写

> 填个金额，直接给出符合票据规范的人民币大写（壹万贰仟叁佰肆拾伍元陆角柒分），元角分、整、零都按规矩写。顺带把日期也写成大写。

[English](README.en.md) | 中文

## 这是什么

报销单、汇款单上要写「壹万贰仟叁佰肆拾伍元陆角柒分」，手写容易错，还要数笔画。这页把规则写进代码。

整数部分四位一组往高位数，组内按千、百、十、个取大写，组间用万、亿、万亿连接；连续零只留一个，组尾的零去掉，开头的「一十五」不写成「壹拾伍」。小数部分按票据规矩：有角无分写「壹角整」，有分无角写「零伍分」，整元写「整」，不足一元补「零元」。

日期那一块两种写法：汉字年月日（二零二六年十月三十一日，公文常见）和逐位大写（贰零贰陆年壹拾月叁拾壹日，票据用）。金额算法先在本机用 node 跑了 16 个边界样例（0、0.05、0.56、1005、一亿零一、九万亿九千九百九十九亿……）才上线。

## 功能

- 金额 → 人民币大写，元角分整零全部按票据规范
- 支持到万亿，最多两位小数
- 同时给出数字、千分位与中文读法，各自可复制
- 日期写成汉字（二零二六年十月三十一日）
- 日期写成逐位大写（贰零贰陆年壹拾月叁拾壹日）
- 五个常用金额快捷入口
- 深色/浅色自适应 + 手动切换
